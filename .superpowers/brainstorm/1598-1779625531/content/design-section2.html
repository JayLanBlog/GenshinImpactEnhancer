关键技术决策

💉 注入方式

CREATE_SUSPENDED → CreateRemoteThread → LoadLibrary
最经典可靠的方式。不碰游戏文件，纯运行时注入。兼容性好，不触发完整性校验。

📡 IPC 通信

游戏内 Overlay → 启动器 用 Named Pipe
性能数据用 Shared Memory (MemoryMappedFile)
前者低延迟指令，后者高吞吐数据——各司其职

🛡️ 反作弊兼容

只 Hook DX Present()，不碰游戏逻辑层。
不修改 .text 段（代码段）——修改输入汇编、显示输出环节，风险最低。
⚠️ 每次游戏更新后需要验证偏移有效性。
