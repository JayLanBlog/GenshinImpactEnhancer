技术选型

UI 技术栈
  • 框架：WPF + .NET 10
  • 风格：Fluent Design · Acrylic · Mica
  • 控件：MaterialDesignInXAML + HandyControl
  • 图表：LiveCharts2（性能好、API 简洁）
  • MVVM：CommunityToolkit.Mvvm
  • 导航：TabControl + 自定义过渡动画
游戏内 Overlay
  • 实现：C++ Direct2D 渲染
  • 位置：屏幕左上角 · 半透明 · 可拖拽
  • 内容：FPS · GPU温度 · 预设名 · 热键提示
  • 触发：Ctrl+Shift+O 显隐
  • 通信：Shared Memory → WPF 进程
  • 性能：< 1ms 额外开销（仅文字渲染）
