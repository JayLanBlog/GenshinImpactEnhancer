🖥️ .NET 桌面 UI 框架选择

「极致 UI/UX」意味着框架选择至关重要。四种主流方案对比：

A

🪟 WPF (Windows Presentation Foundation)

最成熟的 Windows 桌面框架。Fluent Design / Acrylic 效果官方支持，控件库丰富（MaterialDesignInXAML, HandyControl），社区资源极多。.NET 原生，和原项目路线一致。
✅ 成熟稳定 · 控件生态好 · 实时预览窗容易实现

B

🪶 WinUI 3

微软新一代原生框架，支持 Windows 11 最新设计语言。内置亚克力/云母/阴影等现代效果。但生态年轻，控件不如 WPF 丰富，工具链偶有坑。
✅ 原生现代感 · ❌ 生态不够成熟

C

🦖 Avalonia UI

跨平台 .NET 框架，风格类似 WPF 但更现代。可以跑 Windows / macOS / Linux。Fluent 主题支持不错。但你的项目强依赖 Windows（DX Hook），跨平台意义不大。
✅ 跨平台 · ❌ Hook 都是 Windows only，跨平台是伪需求

D

🌐 WebUI 混合方案 (WebView2)

WPF/WinForms 内嵌 WebView2，前端用 React/Vue 写 UI，C# 处理后端逻辑。UI 灵活性最高，但性能开销大，不适合作为游戏 Overlay。
✅ UI 灵活度天花板 · ❌ 内存占用高 · Overlay 性能差

💡 强烈推荐 A（WPF）： 最成熟、控件生态最好、对「极致 UI/UX + 性能仪表盘」支持最到位。WinUI 3 看着新但坑多；你也不需要跨平台。原项目也是这个路线。
